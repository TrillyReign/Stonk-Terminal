# 🚀 Trilly's Stonk Terminal

> A fast, lightweight, and interactive terminal-based tool for investing

## 📌 Features

* ⚡ **Fast & Lightweight:** Low CPU and memory usage with minimal dependencies.
* 🎨 **Interactive TUI:** Keyboard-driven terminal user interface built for speed and efficiency.
* 🛠️ **Customizable:** Easily configure keybindings, themes, and default settings via a simple config file.
* 📦 **Cross-Platform:** Works seamlessly across Linux, macOS, and Windows.

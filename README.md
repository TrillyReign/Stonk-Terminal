# 🚀 Trilly's Stonk Terminal

> A fast, lightweight, and interactive terminal-based tool for investing

## 📌 Main Features

* ⚡ **Fast & Lightweight:** Low CPU and memory usage with minimal dependencies

* 📚 **Fundamental Models:** DCF, GGM, And RIV Models Automatically Calculated When Inputting A Ticker For Quick Deep Value Analysis 

* 🏢 **Insider Transactions:** Live Feed Of Insider Transactions To See What The Insiders Are Doing With Their Shares

* 📰 **Live News Feed:** Live News Feed For Easy Access To Articles, Updates, And SEC Filings

* 📑 **Macro Economics:** Macro Economic Information Right In The Dashboard Including Bonds, Commodities, FED, Indices, And More! 

* 📈 **Tradingview Integration:** Tradingview Integration For Easy Technical Analysis With Custom Indicators

* 🪟 **Windows Resizable:** Easily Resize Windows, Or Overlap Them To Have Tabs To Switch Between


## How To Run: 

1) Install Python (If Not Already Installed) 

2) ''apt update && apt upgrade''

3) ''pip install yfinance && pip install pandas && pip install PySide6''
  
4) Run the script


## API Keys:

To Get All The Features Of This Tool You Will Need An FMP API Key And A FED API Key. Both Of These Are Free. If You Don't Have Them You Will Only Be Missing SEC Filings In The News Feed & Some FED Data. The Terminal Will Still Work & All Models/Features Will Still Run Without Them. They Are Not Required.
